# Apps

The Apps page is where you manage the client applications that are allowed to send print jobs to Qintrix.

This is the access control area of the application.

## Apps List

The index page shows all configured apps.

![Apps index](/images/screenshots/apps-index.png)

### What You Can Do Here

From the apps list, you can:

- view all apps
- search apps
- filter by status
- filter by printer scope
- create a new app
- open app details
- edit an app
- regenerate an API key
- delete one or more apps

## Create App

The create page is used to add a new app that can connect to Qintrix.

![Create app](/images/screenshots/apps-create.png)

### What You Set Here

When creating an app, you can define:

- app name
- API key
- optional description
- whether the app is enabled
- whether it can access all printers or only selected printers

## Edit App

The edit page is used to update an existing app.

![Edit app](/images/screenshots/apps-edit.png)

Use it when:

- the app name changes
- access needs to be restricted or expanded
- the app should be enabled or disabled
- the description should be updated

## App Details

The show page gives a full view of one app.

![App details](/images/screenshots/apps-show.png)

### Why This Page Matters

Use the details page to:

- review the app settings
- copy the API key
- confirm printer access
- regenerate the API key
- move to edit mode
- delete the app

## Important Note About Printer Access

If no printers are selected for an app, that app can access all printers.

If specific printers are selected, the app can only use those printers.

This makes the Apps page very important for controlling who can print where.
