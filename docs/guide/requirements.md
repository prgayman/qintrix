# Requirements

This page explains what you need before you can run Qintrix from source code.

Qintrix runs as a desktop application. Before starting, make sure your computer is ready and has the tools needed to open and run the project.

## What You Need

Before running Qintrix, make sure you have:

- a desktop computer running macOS, Windows, or Linux
- Flutter installed
- the desktop tools for your operating system
- the Qintrix source code on your machine

## Supported Operating Systems

You can run Qintrix from source on:

- macOS
- Windows
- Linux

## Tools You May Need

Depending on your operating system, you may need one of these:

- **macOS**: [Xcode](https://developer.apple.com/xcode/)
- **Windows**: [Visual Studio](https://visualstudio.microsoft.com/downloads/)
- **Linux**: the desktop libraries required by Flutter on Linux

You also need Flutter:

- [Download Flutter](https://docs.flutter.dev/get-started/install)
- [Flutter desktop setup](https://docs.flutter.dev/platform-integration/desktop)

If you want an editor for working with the project, you can use:

- [VS Code](https://code.visualstudio.com/)
- [Android Studio](https://developer.android.com/studio)

## Check Your Setup

After installing Flutter and your desktop tools, run:

```bash
flutter doctor
```

This command helps you confirm that your machine is ready.

If Flutter shows missing items, complete them before trying to run Qintrix.

## If You Want To Test Real Printing

If you want to test actual printing, you also need:

- a printer connected to your computer or local network
- permission to use that printer from your computer
- the printer details needed for setup, such as its name or network address

## Before You Continue

Before moving to the next page, confirm that:

- Flutter is installed
- your computer is supported
- your desktop tools are ready
- `flutter doctor` runs without major problems
- you have the Qintrix project on your machine

After that, continue to the installation page to run Qintrix from source.
