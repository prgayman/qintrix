# Application Pages

This section explains every main page in Qintrix in a simple and practical way.

Use these pages when you want to understand what each area of the application does, what actions are available, and when to use each screen during daily work.

## Main Pages In Qintrix

Qintrix includes these main areas:

- Dashboard
- Server
- Printers
- Jobs
- Apps
- Logs
- Settings
- About App

Each page in this section includes:

- the purpose of the page
- what you can do there
- the most important parts of the screen
- screenshots to help you recognize the layout quickly

## Recommended Reading Order

If you are new to Qintrix, this is a good order:

1. Dashboard
2. Server
3. Printers
4. Apps
5. Jobs
6. Logs
7. Settings
8. About App

## How To Use This Section

- Start with the page you use most often in your workflow.
- If you are setting up Qintrix for the first time, read **Server**, **Printers**, and **Apps** first.
- If you are monitoring daily printing, focus on **Dashboard**, **Jobs**, and **Logs**.
- If you want to change behavior or appearance, go to **Settings**.

The pages below will guide you through each screen in detail.
