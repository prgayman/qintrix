# About App

The About App page explains what Qintrix is and highlights its main operational ideas.

It is a product overview page inside the application.

![About App page](/images/screenshots/about-app.png)

## What This Page Is For

Use the About App page to:

- understand the purpose of Qintrix
- review the main workflow at a glance
- see the main modules of the application
- view product highlights
- check the current app version

## What You Will See

The page usually presents:

- a short explanation of what Qintrix does
- a simplified workflow from setup to printing
- the main modules in the application
- key highlights such as secure app access and reliable job handling
- version information

## When This Page Is Helpful

Open this page when:

- you are new to Qintrix
- you want a quick product overview
- you are introducing the system to a teammate
- you need to confirm the current application build

## Simple Summary

The About App page does not control printing directly.

Instead, it helps you understand the product and how the rest of the pages work together.
