# Dashboard

The Dashboard gives you a quick overview of how Qintrix is performing.

It is the best place to start when you want to check overall activity without opening each page one by one.

![Dashboard overview](/images/screenshots/dashboard.png)

![Dashboard analytics](/images/screenshots/dashboard-2.png)

## What This Page Is For

Use the Dashboard to:

- see whether the server is running
- understand current print activity
- review printer and app totals
- check whether jobs are completing successfully
- spot warnings or unusual trends early

## What You Will See

The Dashboard shows summary cards and charts for:

- total jobs
- completed jobs
- failed jobs
- queued and processing jobs
- total printers and enabled printers
- total apps and enabled apps
- recent log health indicators
- job activity over recent days
- job status distribution
- printer connection type distribution
- content type distribution

## When To Use It

The Dashboard is useful when:

- starting the day and checking system health
- confirming that jobs are flowing normally
- checking whether printers and apps are active
- investigating whether failures are increasing

## Practical Tip

The Dashboard is an overview page, not a configuration page.

If you find a problem here, the next pages to open are usually:

- **Server** for server availability
- **Jobs** for job-by-job status
- **Logs** for event details
- **Printers** for printer setup problems
