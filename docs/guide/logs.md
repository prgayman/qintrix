# Logs

The Logs page stores important application events in one place.

Use it when you need to understand what happened inside Qintrix, especially during troubleshooting.

## Logs List

The main logs screen shows saved log entries.

![Logs index](/images/screenshots/logs-index.png)

### What You Can Do Here

From the list page, you can:

- search logs
- filter by log level
- filter by event type
- open a log entry to view full details

### Common Event Types

The logs may include events related to:

- application startup
- server start, stop, and restart
- server errors
- API authentication failures
- print job creation
- printer test results

## Log Details

When you open one log entry, Qintrix shows the full detail view.

![Log details](/images/screenshots/logs-show.png)

### What You Can See

The detail page can include:

- time of the event
- title
- full message
- level such as info, warning, or error
- event type
- extra metadata when available

## When To Use This Page

Use the Logs page when:

- a printer test failed
- a job was rejected or failed
- the server did not start correctly
- an application could not authenticate
- you need more detail than the Dashboard or Jobs page provides

## Practical Tip

If a problem is happening right now:

1. check the Dashboard for a quick summary
2. open Jobs if the issue is related to a specific print
3. open Logs to find the event that explains the problem
