# Settings

The Settings page controls how Qintrix behaves on your machine.

It is divided into clear sections, so you can update appearance, language, startup behavior, server behavior, and job defaults separately.

## Appearance

The Appearance section controls how the interface looks.

![Settings appearance](/images/screenshots/settings-appearance.png)

Use this section to choose how Qintrix handles light and dark themes.

## Language

The Language section controls the application language.

![Settings language](/images/screenshots/settings-language.png)

Use this section to switch the app language and keep that choice saved for future launches.

## Application

The Application section controls app-level behavior.

![Settings application](/images/screenshots/settings-application.png)

This is where you manage options such as:

- background mode
- start with operating system
- application diagnostics related to startup and tray behavior

Use this section when you want Qintrix to stay available automatically without opening it manually every time.

## Server

The Server settings section controls how the local server behaves.

![Settings server](/images/screenshots/settings-server.png)

Here you can manage:

- server port
- bind IP address
- LAN access
- auto start server

Use these settings when you need other applications or devices to connect to Qintrix correctly.

## Jobs

The Jobs settings section controls queue and retry behavior.

![Settings jobs](/images/screenshots/settings-jobs.png)

Here you can manage:

- whether jobs start paused
- retry attempt limits
- retry delay
- job history retention

These settings help control how Qintrix behaves when jobs fail or when you want to keep history for troubleshooting.

## When To Use The Settings Page

Open Settings when you need to:

- change the theme
- switch language
- change startup behavior
- change server connection settings
- change retry and queue defaults

## Important Tip

Some settings affect how Qintrix behaves immediately, while others affect the next launch or the next server restart.

After changing server-related settings, always confirm that the server is still reachable and working as expected.
