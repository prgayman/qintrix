# Server

The Server page is where you manage the local Qintrix API server.

This server is what allows approved applications to send print jobs into Qintrix.

![Server page](/images/screenshots/server.png)

## What This Page Is For

Use the Server page to:

- check whether the local server is running
- view the current host and port
- start the server
- stop the server
- restart the server
- review recent server-related activity

## Main Information On This Page

The page shows:

- current server status
- runtime or uptime
- start time and last change time
- current host and port
- recent server events
- the latest server error, if one exists

## Main Actions

You can use the action buttons at the top of the page to:

- **Start** the server
- **Refresh / Restart** the server
- **Stop** the server

These actions help when:

- the server is not running
- you changed server settings
- you need to reload the server after troubleshooting

## When To Use It

Open this page when:

- your website or system cannot connect to Qintrix
- you want to confirm the correct host and port
- you need to restart the local server
- you want to review recent server activity

## Important Note

If the server is stopped, Qintrix can still open, but external applications will not be able to send new print jobs until the server is running again.
